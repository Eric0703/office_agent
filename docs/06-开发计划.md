## 6. 关键依赖与风险

| 依赖/风险 | 影响 | 对策 |
|---|---|---|
| Owner 评审与交互确认的时间 | 直接决定日历周期 | 每个 Gate 前 1 天约评审;交互问题集中处理 |
| 内测志愿者招募 | Gate 2 | 提前一周约人;Mock 数据预置,降低试用门槛 |
| 真实办公系统 API 不可得 | A3 适配器 | Mock 继续扛,不阻塞 v1.0 |
| L2 公开语料标注质量 | 现场记录验收 | 标注即验收:Owner 抽检 ≥30% |
