## 1. v2.0 定位

- v2.0 是一次**文档版本重置**:旧文档(docs/ 根下 01~08、protocol.md、05 审查报告)中已接受的结论全部融入本基线正文,不再堆叠修订记录;每份文档只保留当前最终结论。
- v2.0 是**文档集版本**,不是软件产品版本;软件版本仍以正式发布为准(如 Agent v1.0)。
- v2.0 为**候选文档基线**:评审通过前不作为权威来源;评审通过后冻结为有效基线。评审通过前,docs/ 根下旧文档亦仅作历史参考,不作权威来源。

## 3. 效力层级

**03 宪法 > 01/02 需求 > 04 规约 > 05 计划 / 07 架构设计 / 08 协议 / 09 接入规范 > 实现。**

- 06 为汇报版,不参与效力裁定;与其他文档不一致时以被汇报的原文档为准。
- 下层与上层冲突时以上层为准,并发起修正(修正文档,不是绕开)。

## 4. 文档维护规则

- 文档即事实(宪法第 9 条):改行为先改文档,文档与实现同次变更。
- 结论演进**直接修改正文**,不再追加修订记录;文档集版本(v2.0 → v2.1 …)经 Owner 评审后整体推进。
- FR 编号一经发布不复用、不删除(废弃只可标记)。
- 跨文档引用只指向 docs/v2.0/ 内文件;动态进展记录以仓库根 `PROGRESS.md` 为准(见 05 §7)。
